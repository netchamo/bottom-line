# השורה התחתונה

כלי לשליפת כל התגובות מסרטון ביוטיוב, סימון התגובות המעניינות, סידור שלהן ברשימה אחת וייצוא להעתקה, לקובץ טקסט או לאקסל.

## שימוש
1. נכנסים לאתר של הכלי.
2. בפעם הראשונה בכל מכשיר מדביקים מפתח של YouTube Data API v3 ושומרים. המפתח נשמר רק בדפדפן של אותו מכשיר ולא נמצא בקוד.
3. מדביקים קישור לסרטון ולוחצים על שליפת תגובות.

בטלפון אפשר להוסיף את האתר למסך הבית, והוא ייפתח כמו אפליקציה.

## קבצים
- `index.html` – האפליקציה כולה.
- `manifest.webmanifest`, `sw.js`, אייקונים – מה שמאפשר להתקין אותה כאפליקציה.
